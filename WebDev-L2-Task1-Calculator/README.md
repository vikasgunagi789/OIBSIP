## 📌 Project Overview

Calcura is a browser-based scientific calculator designed with a modern and responsive user interface.

It supports both basic arithmetic operations and scientific mathematical functions.

The calculator also provides keyboard support, DEG/RAD angle modes, theme switching, error handling, and responsive layouts for different screen sizes.

---

## ✨ Features

### Basic Calculations

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal calculations
- Parentheses
- Clear button
- Delete button
- Equals button

### Scientific Functions

- Sine
- Cosine
- Tangent
- Inverse Sine
- Inverse Cosine
- Inverse Tangent
- Logarithm
- Natural Logarithm
- Square Root
- Square
- Power
- Factorial
- Pi
- Euler's Number
- Sign Change

### Additional Features

- DEG / RAD angle mode
- Keyboard support
- Light / Dark theme
- Responsive design
- Division-by-zero protection
- Invalid input handling
- Modern UI
- No inline `onclick` attributes
- No `eval()` function
