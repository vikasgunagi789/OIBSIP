# TaskFlow — To-Do Web App

A modern, responsive To-Do List web application built using
HTML5, CSS3 and Vanilla JavaScript.

This project was created as part of the OASIS INFOBYTE
Web Development & Designing Internship.

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Pending task counter
- Completed task counter
- Total task counter
- Task timestamps
- Search tasks
- Filter tasks by All, Pending and Completed
- Clear all completed tasks
- Empty-state messages
- Tasks persist after page refresh
- Dark / Light mode
- Responsive design
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- DOM Manipulation
- localStorage
- Google Fonts
