# 🇮🇳 Dr. A. P. J. Abdul Kalam — Tribute Page

A responsive and interactive tribute website dedicated to
Dr. A. P. J. Abdul Kalam — scientist, educator, author and
former President of India.

This project was created as part of the OASIS INFOBYTE
Web Development & Designing Internship.

---

## 🌐 Live Demo

https://vikasgunagi789.github.io/OIBSIP/WebDev-L2-Task2-TributePage/

---

## 📖 About the Project

This website presents the life, achievements, journey and
legacy of Dr. A. P. J. Abdul Kalam through a modern,
responsive web interface.

The design focuses on typography, visual hierarchy,
responsive layouts, animations and interactive elements.

---

## ✨ Features

- Responsive design
- Fixed navigation bar
- Smooth scrolling
- Hero section
- Biography section
- Important life milestones
- Timeline
- Achievement cards
- Inspirational quote section
- Legacy section
- Dark / Light mode
- Theme preference saved using localStorage
- Scroll reveal animations
- Active navigation highlighting
- Mobile-friendly layout
- Modern typography
- Accessible image alt text

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox
- Google Fonts
- DOM Manipulation
- Intersection Observer API
- localStorage
