# Login Authentication System

A responsive client-side authentication system built as part of the OASIS INFOBYTE Web Development Internship.

## Features

- User registration
- Email validation
- Password validation
- Duplicate email detection
- SHA-256 password hashing
- User login
- Protected dashboard
- Logout functionality
- localStorage-based session management
- Responsive UI

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web Crypto API

## Project Structure

- register.html — Registration page
- login.html — Login page
- dashboard.html — Protected dashboard
- style.css — Complete styling

## How to Run

Open `register.html` in a modern web browser.
